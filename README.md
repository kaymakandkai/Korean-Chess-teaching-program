# 와룡장기 (臥龍將棋)

장기를 **두고, 배우고, 이기는** 프로그램입니다. 브라우저에서 바로 실행되는 웹 앱이며, 설치 없이 정적 파일로 배포할 수 있습니다.

| 모드 | 내용 |
| --- | --- |
| **AI 대국** | 초보(17급) · 하수(13급) · 중수(8급) · 고수(2급) · 초고수(2단) · 전설(9단) 6단계 AI와 대국 |
| **상황별 대국** | 엔진으로 검증한 연습 지형 16가지 + 직접 말을 놓고 그 장면부터 두기 |
| **2인 대국** | 온라인 매칭은 서버 추가 후 제공 예정. 지금은 한 기기에서 둘이 두기 |
| **교습** | 한 수 둘 때마다 AI 코치가 상황·추천수·위험·몇 수 뒤의 위험을 구체적으로 설명 |

## 실행

```bash
npm install
npm run dev          # 개발 서버 (http://localhost:5173)
npm test             # 규칙·엔진·연습 지형 검증 테스트
npm run build        # dist/ 에 정적 사이트 생성
npm run build:single # dist-single/index.html 하나로 묶은 버전
```

## 대국 설정 (AI 대국 · 교습 · 2인 대국 공통)

- **진영**: 초(파랑) / 한(빨강). 내가 고른 진영이 화면 아래쪽에 옵니다.
- **선수**: 초 먼저 / 한 먼저. 나중에 두는 쪽이 덤 1.5점을 받습니다.
- **마상 차림**: 초와 한 각각 `마상마상`(오른상) · `상마상마`(왼상) · `마상상마`(안상) · `상마마상`(바깥상).
  각 플레이어가 자기 쪽에서 바라본 왼쪽→오른쪽 순서입니다.
- **기물 떼기(접장기)**: 초·한 각각 프리셋(차, 포, 마, 상, 차·포, 양차…)을 고르거나, 미리보기 판에서 기물을 눌러 직접 떼고 되돌릴 수 있습니다.
- **규칙**: 빅장 사용 여부, 수 제한(도달 시 점수 판정).

## AI 난이도

모든 단계가 같은 탐색 엔진을 쓰고, 탐색 깊이·생각 시간·실수 확률로 급수를 흉내냅니다.

| 단계 | 급수 | 방식 |
| --- | --- | --- |
| 초보 | 17급 | 1수 앞, 큰 무작위성, 30% 확률로 아무 수 |
| 하수 | 13급 | 2수 앞, 12% 확률로 실수 |
| 중수 | 8급 | 3수 앞, 가끔 실수 |
| 고수 | 2급 | 5수 앞, 작은 무작위성 |
| 초고수 | 2단 | 최대 3초, 최선수만 |
| 전설 | 9단 | 최대 8초, 매 수 수십만~수백만 국면 탐색 |

엔진: 반복 심화 알파베타(PVS), 치환표, 널무브(=한수 쉼), 늦은 수 줄이기(LMR), 킬러·히스토리 정렬, 정지 탐색.
급수는 사람 기준의 근사치입니다.

## 교습 코치가 매 수 알려 주는 것

1. **방금 둔 내 수 평가**: 최선수 / 좋은 수 / 무난한 수 / 아쉬운 수 / 실수 / 큰 실수, 최선 대비 손해 점수,
   왜 좋은지·나쁜지, 더 좋은 수와 그 이유, 실수라면 상대의 예상 응수.
2. **상대 수 해설**: 상대가 무엇을 잡았는지, 무엇을 노리는지, 장군·멍군·빅장 여부.
3. **지금 상황**: 몇 번째 수, 초반/중반/종반, 형세(우세 정도), 기물 점수(덤 포함), 기물 차이, 궁 안전.
4. **지금 위험한 것**: 장군, 상대의 외통 위협, 공격받는 내 기물(지켜지는지, 교환하면 몇 점 손해인지), 상대의 노림수.
5. **추천 수와 이유**: 후보 최대 3개 — 기물 잡기·교환 손익, 장군, 외통 수순, 위협 해소, 양걸이, 궁성 압박, 전개 등. 예상 수순 포함.
6. **몇 수 뒤의 위험**: 추천 수 뒤 상대의 예상 응수와 의도, 수순 속의 장군·기물 손실, 대비하지 않으면 몇 수 뒤 생기는 위협,
   궁과 같은 줄의 상대 포·차, 열린 줄의 상대 차, 궁성에 다가온 졸 등.
7. **배움 한마디**: 다리 없는 포, 멱이 막힌 마, 전개되지 않은 기물 등 지금 국면에 맞는 조언.

판 위에는 추천 수(초록), 다른 후보(파랑), 상대의 노림수(빨강) 화살표와 공격받는 기물 표시가 나타납니다.

## 상황별 대국: 연습 지형

| 분류 | 지형 |
| --- | --- |
| 외통 연습 | 양차 외통 · 포·차 연계 외통 · 졸의 궁성 침투 · 마·차 외통 · 궁성 대각선의 차 |
| 전술 | 마의 양걸이 · 다리 놓기 양수겸장 |
| 수비 | 장군 받기 · 포 장군 막기 · 외통 위협 막기 · 단 하나의 수비 |
| 종반 | 차·졸로 마무리 · 마·졸 연계 · 차·마로 궁성 공략 · 졸 넷의 힘 |
| 대국 | 차 떼고 두기 |

각 지형에는 목표(예: "2수 안에 외통", "3수 동안 큰 손해 없이 버티기"), 배울 점, 단계별 힌트가 있고,
`tests/scenarios.test.ts`가 모든 지형이 설명대로 성립하는지 엔진으로 검증합니다.
수비 지형 일부는 엔진 자가대국에서 "버티는 수가 1~2개뿐인 실전 장면"을 골라낸 것입니다.

**직접 배치하기**에서는 판에 말을 놓고, 먼저 둘 쪽·내 진영·AI 난이도·교습 조언·빅장을 정해 그 장면부터 둘 수 있습니다.
궁·사의 위치, 기물 개수, 차례가 아닌 쪽의 장군 여부를 자동으로 검사합니다.

## 구현한 규칙

- 모든 기물의 이동 (궁성 대각선의 궁·사·차·포·졸 포함, 마·상의 멱, 포는 포를 넘거나 잡지 못함)
- 장군이면 장군을 피하는 수만 허용, 외통 시 패배
- 한수 쉼 (장군 중에는 불가, 양쪽 연속이면 점수 판정)
- 빅장 (켜면: 궁이 마주본 상태를 상대가 피하지 않으면 무승부)
- 같은 국면 3회 반복 시 무승부
- 수 제한 도달 시 점수 판정 (차13 포7 마5 상3 사3 졸2, 후수 덤 1.5)
- 기보 표기: `82포85` (가로줄 위에서부터 1~9·0, 세로줄 왼쪽부터 1~9, 초 기준)

## 구조

```
src/
  engine/          장기 엔진 (UI와 독립, Node에서도 동작)
    position.ts    보드·수 생성·공격 판정·수 두기/무르기
    search.ts      탐색 엔진
    eval.ts, pst.ts  형세 평가
    levels.ts      AI 난이도
    coach.ts       교습 코치 (국면 분석 · 수 평가 · 한국어 설명)
    tactics.ts     교환 계산(SEE), 공격받는 기물, 장군 기물
    game.ts        대국 진행·승패 판정
    setup.ts       마상 차림·기물 떼기·배치 검증
    service.ts     워커에서 처리하는 요청 (AI 수, 분석, 수 평가, 힌트)
  worker/          웹 워커 (AI용·코치용 2개, 워커 불가 환경에서는 메인 스레드로 대체)
  ui/              화면 (메뉴, 설정, 대국, 코치 패널, 상황별, 편집기, 2인 대국)
  scenarios.ts     연습 지형
tests/             규칙·엔진·코치·연습 지형 테스트
```

## 2인 대국(온라인 매칭) 확장 계획

- 대국 진행은 `Game`(src/engine/game.ts)이 시작 국면 + 수 목록으로 관리하므로, 서버와는 **수(move)만 주고받으면** 됩니다.
- 대국 화면은 이미 `local` 모드(두 사람이 번갈아 두기)를 지원합니다. 온라인 모드는 상대 차례에 AI 대신
  서버(WebSocket)에서 수를 받아 `apply()`하도록 연결하면 됩니다.
- 서버 쪽에서도 같은 엔진 코드로 수의 합법성 검사·승패 판정을 할 수 있습니다 (엔진은 DOM에 의존하지 않음).
